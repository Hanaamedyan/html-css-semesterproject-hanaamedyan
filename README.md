# html-css-semesterproject-hanaamedyan

Community Science Museum - Semester Project

This project is my semester assignment for the Front-End Development program at Noroff. The main goal of this project was to design and build a responsive multi-page website for a fictional museum. The website is created by only using HTML and custom CSS, while following DRY principles, and user experience.

## Project Purpose

The website I have built is designed to inspire curiosity amongst adults and children. It includes multiple sections - all styled with a cohesive design system using root variables.

## Technologies Used

- HTML5 - Semantic structure
- CSS - Custom styling and responsive layout
- No JavaScrip - Not allowed in this project
- GitHub - Repository & project planning

## Features

- Fully responsive multi-page layout
- Consistent design system
- Acessible navigation and semantic markup
- Interactive pages
